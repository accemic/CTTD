# from_etrace - Third-party benchmark inputs (fetched on demand)

The `examples/all/` compression benchmark runs on a set of RISC-V ELF
binaries (CoreMark, Dhrystone, Embench, riscv-tests, ...) and their Spike
PC traces. **These third-party artifacts are not stored in this repository.**
They are pulled from their upstream source on demand and are git-ignored.

## Why they are not committed

These binaries and traces are produced by, and belong to, third parties with
their own licenses and redistribution terms. Shipping the compiled artifacts
here would mean redistributing third-party works without their accompanying
license/attribution. To stay clean, this repo ships only a fetch script that
reconstructs the files locally from the original upstream.

In particular, **CoreMark** (EEMBC) has its own license with redistribution,
naming and reporting requirements, and **Spike** (RISC-V ISA simulator) is
BSD-licensed and must travel with its license text. We therefore do not
redistribute either; the fetch script obtains them from upstream instead.

## How to get the files

Run:

    ./fetch.sh

This populates exactly the paths `examples/all/makefile` expects, so the
benchmark then runs unchanged:

    test_files/*.riscv      - 36 RISC-V ELF binaries (copied as-is)
    spike/spike.tar.gz      - all *.spike_pc_trace_filtered PC traces

Requirements: `git`, `cmake` (>=3.10), `dtc` (device-tree-compiler),
`python3`, `tar`/`bzip2`. A full RISC-V toolchain is **not** required - the
upstream referenceFlow ships its own pre-built `spike` and `objdump`.

Environment overrides: `RTS_COMMIT` (pin a different revision), `RTS_REPO`,
`RTS_CACHE` (checkout cache), `FORCE=1` (regenerate even if present).

## Source and licenses

All inputs come from the RISC-V Trace Specification *referenceFlow*:

    https://github.com/riscv-non-isa/riscv-trace-spec/tree/main/referenceFlow

`fetch.sh` pins a specific upstream commit. The `.riscv` binaries live under
`referenceFlow/tests/test_files/`; the `*.spike_pc_trace_filtered` traces are
generated by running the referenceFlow Spike regression. The referenceFlow is
BSD-2-Clause / MIT licensed (see its `LICENSES/` directory). The original
source projects keep their own licenses, which apply at their upstreams:

| Input(s)                                    | Project / origin            | License (at upstream)            |
|---------------------------------------------|-----------------------------|----------------------------------|
| `coremark.riscv`                            | EEMBC CoreMark              | EEMBC CoreMark license (reporting/naming terms) - github.com/eembc/coremark |
| `dhrystone.riscv`                           | Dhrystone (Reinhold Weicker)| Permissive / public-domain style |
| `embench-*.riscv`                           | Embench-IOT                 | Mixed permissive (per-benchmark; GPL/BSD/MIT) - github.com/embench/embench-iot |
| `median, mm, mt-*, multiply, qsort, rsort, spmv, towers, vvadd, pmp` | riscv-tests | BSD - github.com/riscv-software-src/riscv-tests |
| `pk.riscv`                                  | RISC-V proxy kernel (pk)    | BSD - github.com/riscv-software-src/riscv-pk |
| `br_j_asm, test_discon_branch_exception, xrle` | riscv-trace-spec referenceFlow | BSD-2-Clause / MIT |
| `spike.tar.gz` (PC traces)                  | Generated with Spike (riscv-isa-sim) | BSD - github.com/riscv-software-src/riscv-isa-sim |

If you redistribute any of these artifacts yourself, include the respective
upstream license/attribution. This repository does not redistribute them.
